## 本集主題（含 emoji 意象解讀）

**👻 幽靈（Ghost）**：「鬼故事」是台灣股市術語，指刻意散布以動搖持股信心的空頭謠言。本集核心事件正是如此——CCL（銅箔基板）「降規降級」傳言，讓台光電、聯茂、台燿等 CCL 族群同步重挫，謝孟恭卻在「鬼故事」之中逆向拆解：CPO 消除的只是部分長距銅連，PCIe Gen6/7、CXL 等高速介面仍強制要求 M7 以上材料，長期升規趨勢並未終結。「幽靈」既是市場散布的恐慌，也是謝孟恭用理性解剖後讓它消形的東西。

本集圍繞三條主線：其一是 **台積電漲價傳聞**（10%）引發的供應鏈漲價連鎖——從晶圓到記憶體到顯卡，謝孟恭逐層拆解成本轉嫁結構，並指出黃仁勳早已暗示「台積電太便宜了」；其二是 **CCL 降規鬼故事的本質**——CPO 技術的局限性與 PCIe Gen6 硬性規格需求，讓市場的急跌成為逆向機會的確認信號；其三是謝孟恭自東京電玩展（TGS 2026）歸來後，分享**肖楠資本**進軍獨立遊戲創投的最新佈局與策略方向。

## 一、重點摘要

### 1. 台積電漲價傳聞：AI 需求撐出定價權

市場傳言台積電計劃 2027 年起對先進製程晶圓漲價最高 10%，謝孟恭認為此為合理預期，並非空穴來風。

| 論據 | 內容 |
|------|------|
| 黃仁勳（Jensen Huang）公開表態 | 曾明言台積電「太便宜了」（priced too cheaply），隱示應享有更高定價 |
| 台積電管理層立場 | 表示應與客戶「共同成長」，成本緊繃時調價屬正常商業行為 |
| 供需現實 | 台積電先進製程晶圓產能持續供不應求，即使 2025 年展開全球大規模擴廠，仍難跟上 AI 相關需求 |
| 市場份額 | 台積電在第三方晶圓代工市場市佔率超過 70%，定價議價能力強 |

謝孟恭核心論點：**「要漲就不會只漲 AMD，是大家都漲。」** 這不是個別廠商的弱點，而是整個供應鏈的成本重置。台積電 2026 年資本支出已上調至 600～640 億美元，其中 70%～80% 投入先進製程，充分顯示台積電的戰略自信。

### 2. AMD 漲價解構：記憶體才是主角

市場把 AMD 消費級產品漲價直接歸因於台積電，謝孟恭拆解認為此論述不精確：

| 成本來源 | 影響程度 | 說明 |
|----------|----------|------|
| 台積電晶圓 | 次要（約 10% 漲幅） | 確為成本之一，但占顯卡總成本比例有限 |
| 記憶體（GDDR6X） | 主要 | HBM / GDDR 漲幅遠大於晶圓，才是板卡成本攀升主因 |
| NVIDIA 套件銷售 | 隱形漲價機制 | NVIDIA 已將 GPU 與 GDDR 打包售予 AIC（板卡廠），成本壓力早已悄然轉嫁消費者，MSRP 失去參考價值 |

謝孟恭指出，真正推升消費者付出代價的是記憶體短缺——部分廠商討論從 8-High HBM 堆疊降至 4-High 以緩解缺貨，而 Rubin GPU 實際功耗尚未達到最高規格，Power Rack 需求遞延，但這些都屬短期調配，不改長期需求向上趨勢。

### 3. CCL 降規「鬼故事」的本質拆解

CCL 族群因「降規至 M4 材料」傳言而重挫，謝孟恭以三個層次拆解鬼故事的盲點：

**（一）CPO 技術的誤讀**

CPO（Co-Packaged Optics，共封裝光學）確實可以消除機箱內部分可插拔光模組與長距走線，但：
- CPO 針對的是「交換機至交換機」的光纖連接，並非所有板卡走線
- CPU-GPU 之間的 PCIe Gen6 / Gen7 介面、CXL 記憶體擴充介面、CX9 高速網路卡仍須走板材
- **板材廠商已明確表示**：導入 PCIe Gen6 需從 M6 升級至 M7，沒有降規空間

**（二）高速介面升規時間表**

| 介面標準 | 所需板材等級 | 備註 |
|----------|-------------|------|
| PCIe Gen5（現行） | M6～M7 | 已在大量量產 |
| PCIe Gen6（近期） | M7（必要） | 頻率翻倍，信號完整性要求更嚴 |
| PCIe Gen7（未來） | M8 以上 | 仍在規格制定階段 |
| CXL 記憶體介面 | M7 以上 | AI 伺服器記憶體池化的關鍵介面 |

**（三）「光進銅退」只是局部**

謝孟恭認為，過去「光進銅退」曾打爆銅纜相關類股，後來一堆都噴回新高。CCL 降規故事的本質是同樣的套路：**「短期鬼故事無法改變硬體升級的長期趨勢。」** 市場急殺反而是確認持股信心的時機，而非出場訊號。

### 4. GB200 機架數字的冷靜反思

謝孟恭回顧 GB200 NVL72 機架（rack）的預估值演化：

| 時間點 | 市場預估 rack 數 | 說明 |
|--------|-----------------|------|
| 樂觀高峰（2025 年） | 70,000＋ | 市場高估需求，部分分析師用「路線圖野心」直接當出貨量 |
| 修正後估算（理性研究） | 約 20,000 | 認真研究後還原的可執行量 |

謝孟恭觀點：高估不代表需求消失，仍屬「研發中路線圖」的自然修正。**數字縮水時不要恐慌，那是從樂觀夢境降落到務實現實，不是需求消失。** 最終這些 rack 仍將出貨，只是時間軸拉長。

### 5. 台股盤面「無連續性」現象

謝孟恭觀察近期台股盤面：

- 個股頻繁出現「突破後立刻拉回、動能斷裂」的走勢格局
- 短線追動能的操作者因此連續受損，屢買屢套
- 謝孟恭定性：**「無連續性的盤面才是常態，過去超級熱鬧的連續上漲盤是例外。」**
- 建議策略：控制槓桿、以長期持股取代頻繁進出，在常態盤面中減少摩擦成本

### 6. 肖楠資本：東京電玩展觀察與獨立遊戲創投佈局

謝孟恭親赴東京電玩展（TGS 2026，9 月 17 日起於幕張展覽館舉行），分享肖楠資本的最新進展：

| 項目 | 內容 |
|------|------|
| 資金規模 | 目標 3 億新台幣管理資產（2026 年底前） |
| 合作夥伴 | 嘖嘖（眾籌平台），補足台灣遊戲資金缺口 |
| 已投資案例 | 《紅眼露比》、《Night Rampage》等台灣團隊 |
| 肖楠資本定位 | 「掏錢加發行行銷」——資金 + 法務 + 簽約 + 發行行銷，不干涉開發 |
| 差異化主張 | 「掏錢加上不囉唆、不要一堆 cut」，讓開發者安心做遊戲 |
| 地理佈局 | 現以台灣為核心，已接觸海外歐美團隊，後續規劃設立亞洲樞紐與歐洲 hub |

謝孟恭在 TGS 觀察到獨立遊戲團隊普遍缺乏「優質發行商加行銷」支援，進一步確認肖楠資本的市場缺口定位正確。

## 四、投資心法與金句

1. **「要漲就不會只漲 AMD，是大家都漲。」**——謝孟恭點破成本轉嫁邏輯：供應鏈各層都在調價，單獨把漲價問題貼在某一家身上是對供應鏈結構的誤讀。

2. **「短期鬼故事無法改變硬體升級的長期趨勢。」**——對 CCL 降規謠言的核心反駁。謝孟恭認為，鬼故事往往打出最深的坑，也往往提供最明確的逆向進場確認信號。

3. **「晶片旁轉光打爆銅纜相關類股，後來一堆都噴回新高。」**——借歷史案例說明市場對「新技術替代舊材料」的恐慌往往過度，最終供需修正都回到基本面。

4. **「無連續性的盤面才是常態，過去超級熱鬧的盤是例外。」**——提醒投資人重置對市場的期待值：不要把例外的熱鬧行情當作基準線，應適應常態盤面中的節奏，減少不必要的進出摩擦。

5. **「掏錢加上不囉唆、不要一堆 cut。」**——謝孟恭對肖楠資本價值主張的精煉表述，強調尊重創作者、提供資源而不干涉開發自主，是對台灣遊戲生態真正需要的填補。

6. **「數字縮水時不要恐慌，那是從樂觀夢境降落到務實現實。」**——對 GB200 機架數字從 7 萬修正到 2 萬的理性解讀，長期需求未消失，短期調整是路線圖落地的必經過程。
