## 本集主題（含 emoji 意象解讀）

本集沒有在節目頁另列副標題，開場文案是「可能生來就是喜歡擔心東擔心西」。內容由運動與生活閒聊切入，核心回到「台股逼近五萬點時，如何配置與控制回撤」。

🏈（美式足球）可解讀為本集的意象：行情仍在進攻、指數向前推進，但投資人也要像球賽一樣判斷持球、攻守轉換與失誤風險。這是編輯對 emoji 的意象解讀，不是主持人對符號的正式說明。

## 一、重點摘要

- 主持人談近期打網球、減重、跑步與買自行車，強調長期目標要拆成可執行的階段，否則昂貴器材可能只會被掛在牆上。
- 台股曾突破五萬點，之後回到約 49,800 點附近。主持人認為，若把 3–5 月極端強勢行情當作標準，其他時間都會被誤認為盤勢很差；比較合理的判斷是把當下視為「正常的好」。
- 他以 EPS 成長與指數估值的角度認為五萬點不一定是終點，但同時提醒供應鏈狂潮終究可能大幅回檔，投資人現在就應思考如何降低部位受傷程度。
- 主持人目前不採傳統股債配置，而偏好股票內部的風控：大盤創高、個股卻連月沒有創高時，先剪掉轉弱標的、保留現金；強勢股則不急著過早賣出。
- 「缺貨、漲價」題材之外，可留意缺貨改善後靠出貨量受惠的族群，作為對沖；這是產業方向的概念，節目摘要沒有給出具體台股名單，不能自行補成主持人推薦個股。
- QA 談到趨勢判斷、期貨轉倉成本、質押／借貸的比較，以及如何跳出原本生活圈。主持人強調月線、季線斜率與扣抵值可作為觀察工具，但真正困難的是打敗大盤與同儕，仍須回到基本面與 EPS 趨勢。
- 長抱案例提到聽眾由 Yandex 持有到公司轉型、改名為 Nebius 後的 NBIS；主持人用此說明長期持有不是「什麼都不做」，而是每天都在重新判斷是否仍值得持有。

## 四、投資心法與金句

### 投資心法

1. 不用最瘋狂的行情當作日常基準；先辨識「正常的好」與真正轉弱。
2. 大盤創高而個股連月不創高時，優先處理弱勢部位，必要時先留現金，不要為了滿倉而追高。
3. 強勢股不必太早砍，但要設定可承受的持股水位區間；風控不是把現金拉到極高，而是避免流動性差的股票在下跌時賣不出去。
4. 技術面可協助辨識趨勢，基本面仍要看 EPS 成長趨勢；目標不是只猜對方向，而是取得相對報酬。
5. 長期持有需要持續研究與重新判斷。公司轉型後仍值得持有，才是「抱得住」的理由，不是因為買進後完全不看。
